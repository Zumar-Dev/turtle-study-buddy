A teen-friendly AI study companion with a cute, friendly turtle mascot.
Ask a question, get a clear explanation, and learn step by step.

> Status: work in progress. Features are being added step by step.

## What it is

Turtle Study Buddy helps students understand what they are studying
instead of just copying answers. The turtle talks in a friendly,
easy-to-follow way.

## Planned features

- Chat with the turtle about your study topics
- A talking, animated turtle with lip-synced voice
- Guided classroom-style explanations
- A focus timer for study sessions
- Mobile and desktop friendly design

## Built with

- HTML, CSS and JavaScript
- Free tools only (GitHub and Cloudflare Pages for hosting)

## Privacy

This project does not ask students for personal information.
Please do not enter your full name, school, phone number or address.
